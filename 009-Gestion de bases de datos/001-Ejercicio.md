MongoDB 

Es una base de datos NoSQL
Se ha convertido en NOSQL

No SQL = No es SQL
NOSQL = Not Only SQL

Vamos  hacia una fusion de las dos tecnologías

Las bases de datos SQL son buenas guardando tablas
Las bases de datos NoSQL (MongoDB) son buena sguardando documentos

Yo tengo un lostado de clientes?
Todo aquello cuyo espacio natural es un excel, se suele guardar en SQL

Yo tengo un listado de documentis?
Todo aquello cuyo espacio natural es un documento, se suele gradar en MondoDB

Yo tengo un conjunto de documentos y lo que busco es similitud entre ellos?
Se suele usar ChromaDB (BD vectoriales)
